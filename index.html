ย้อนกลับ

  • ./rollback.sh = kubectl rollout undo deploy/api deploy/bo แล้วรอ rollout (image เก่ายังอยู่บน Docker Hub)
  • ถ้า migration เปลี่ยน schema จน code เก่าใช้ไม่ได้ ต้อง restore RDS จาก snapshot pre-<tag> ด้วย สคริปต์พิมพ์คำสั่งให้
  • migration จึงต้อง backward-compatible (expand → migrate → contract) เพราะ pod เก่าและใหม่รันพร้อมกันระหว่าง rolling update

งานประจำ

  • เปลี่ยน secret แก้ app-secrets.env → ./4_create_secrets.sh → kubectl rollout restart deploy/api deploy/bo
  • ดู log ./logs.sh api 200 · FOLLOW=1 ./logs.sh bo · ./logs.sh migrate
  • เพิ่มเครื่อง ./add_node.sh 1 แล้วแก้ AGENT_COUNT ใน .env
  • ทดสอบ HPA ./load_test.sh 120 (ก่อนเปิดใช้งานจริง)
  • DB ./connect_rds.sh แล้ว DBeaver / pg_dump ที่ localhost:15432
